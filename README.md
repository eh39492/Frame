# Frame

## What
A holder that can hold a basic sheet image. contains 2 images: one of a butterfly and one of a landscape.

## How to use

Download the STL file or go to this link to get a file of your choice:

[Onshape Model](https://cad.onshape.com/documents/07fa6d59cc09d5dbe4ff9db8/w/5cce2ea085623e5a13f74568/e/bac12b2c0d4985ae1dd9f93e?renderMode=0&uiState=6af516f8f149f1ccf121fadd)

Then use a slicer like Bambu Studio to slice. Enable supports, and all other default settings will work. Then print and enjoy!!! Slot the image in with the thi slide in the slot.

## Design

Made entirely in Onshape using common tools.
